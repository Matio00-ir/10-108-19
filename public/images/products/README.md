# تصاویر محصولات

فایل‌های تصویر محصولات را با نام `<slug>.webp` در همین پوشه قرار دهید.
فهرست کامل نام فایل‌ها و پرامپت‌های Gemini در `docs/IMAGE-PROMPTS.md` است.

پس از قرار دادن تصاویر، در `lib/constants.ts` مقدار `PRODUCT_IMAGES_ENABLED` را `true` کنید.
تا آن زمان، کارت‌ها و گالری از تصویر جایگزین SVG برندشده استفاده می‌کنند.
